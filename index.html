환율계산기 개인정보처리방침

시행일: 2026년 9월 8일

앱 이름: 환율계산기

Android 패키지: com.takek.currencycalculator

1. 개인정보 처리 개요

환율계산기는 사용자의 개인정보 보호를 중요하게 생각합니다. 앱은 회원가입이나 로그인을 요구하지 않으며, 이름, 이메일 주소, 전화번호, 주소, 연락처, 위치정보 등의 개인 식별정보를 개발자가 앱을 통해 직접 수집하거나 저장하지 않습니다.

현재 앱에는 위치정보, 연락처, 사진·카메라, 마이크, 전화번호를 이용하는 기능이나 결제 기능이 없습니다. 사용자 행동 분석, Firebase, Crashlytics 및 사용자 추적 SDK를 사용하지 않습니다.

2. 앱에서 사용하는 로컬 데이터

편리한 사용과 오프라인 환산을 위해 다음 설정 및 캐시를 사용자 기기의 앱 내부 저장소에 저장합니다.

  • 최근 사용한 통화 목록(최대 4개)
  • 마지막으로 선택한 출발 통화와 도착 통화 조합
  • 마지막으로 받은 환율 데이터와 오프라인 사용을 위한 캐시
  • 환율 데이터 기준 시각, 다음 갱신 예정 시각 및 기기에서 데이터를 받은 시각

이 데이터는 사용자의 이름이나 계정을 식별하기 위한 정보가 아니라 앱 기능을 위한 설정과 캐시입니다. 앱은 이를 개발자의 별도 서버에 업로드하지 않으며, 개발자는 해당 데이터를 원격으로 열람하거나 보관하지 않습니다. 기기 운영체제의 백업은 제7항을 참고해 주세요.

계산기에 입력한 금액은 계산 중 메모리에서 사용하며, 앱의 영구 저장소에 저장하거나 환율 서버에 전송하지 않습니다. 앱을 완전히 종료한 뒤 다시 실행하면 입력 금액은 0으로 시작합니다.

3. 환율 정보 제공을 위한 외부 서비스

앱은 환율 정보 제공을 위해 ExchangeRate-API Open Access 서비스를 사용합니다. 환율 데이터를 받을 때 https://open.er-api.com/v6/latest/USD에 HTTPS 요청을 보냅니다. 앱은 이 요청에 사용자의 입력 금액, 최근 통화 목록 또는 마지막 선택 통화 조합을 포함하지 않습니다.

인터넷 통신 과정에서 IP 주소와 요청 시각 등 일반적인 접속 기술정보가 해당 서비스 제공자 또는 그 서비스의 네트워크 인프라에서 처리될 수 있습니다. 개발자는 ExchangeRate-API의 서버 접속 로그를 직접 수집하거나 보관하지 않습니다.

해당 서비스의 데이터 처리에는 서비스 제공자의 이용약관 및 개인정보 관련 정책이 적용될 수 있습니다. 자세한 내용은 ExchangeRate-API 이용약관 및 개인정보 관련 정책을 확인해 주세요.

앱은 기기의 네트워크 연결 상태를 확인하여 오프라인 표시와 환율 갱신 여부를 결정합니다. 이 상태를 개발자 서버로 전송하지 않습니다.

이 개인정보처리방침 페이지는 GitHub Pages를 통해 제공됩니다. 페이지를 브라우저로 열거나 외부 링크를 방문하면 IP 주소 등 접속 기술정보가 해당 웹사이트 운영자에게 전달될 수 있습니다. 이 페이지 자체에는 광고, 사용자 입력 양식 또는 별도의 분석·추적 스크립트가 없습니다. GitHub의 처리는 GitHub 개인정보처리방침을 참고해 주세요.

4. 개인정보 제3자 제공

개발자는 사용자의 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 다만 환율 정보를 제공하기 위한 외부 API 통신과 사용자가 웹페이지를 여는 과정의 통신은 제3항에서 설명한 범위에서 발생합니다.

5. 광고

현재 환율계산기 앱에는 광고 SDK나 광고 기능이 포함되어 있지 않습니다.

6. 회원가입 및 계정

앱은 회원가입 또는 사용자 계정 생성을 요구하지 않습니다. 앱 자체의 사용자 계정이나 로그인 정보를 관리하지 않습니다.

7. 데이터 보관 및 삭제

설정 및 캐시는 사용자 기기 내부에 보관되며, 통화를 선택하거나 새 환율을 받으면 갱신됩니다. 개발자는 이 데이터를 별도 서버에 보관하지 않습니다.

Android 설정에서 환율계산기의 앱 데이터 또는 저장공간을 삭제하면 현재 기기의 로컬 설정과 캐시를 삭제할 수 있습니다. 앱을 제거할 때도 해당 기기의 앱 데이터가 삭제될 수 있습니다.

현재 앱은 Android의 기본 앱 데이터 백업을 허용합니다. 기기 설정과 운영체제의 백업 정책에 따라 앱 데이터가 운영체제 또는 사용자가 선택한 백업 서비스에 백업되고, 재설치나 기기 이전 시 복원될 수 있습니다. 이는 개발자 서버로의 업로드와는 별개이며 개발자는 해당 백업에 접근하지 않습니다. 백업본의 삭제와 복원 설정은 기기 또는 백업 서비스에서 관리해 주세요.

외부 서비스의 접속정보 보관 및 삭제는 해당 서비스의 정책을 따릅니다.

8. 아동의 개인정보

앱은 아동의 개인정보를 의도적으로 수집하지 않습니다. 단순 환율 조회 및 계산 기능을 제공하는 일반 사용자 대상 도구입니다.

9. 개인정보처리방침 변경

앱 기능 또는 사용하는 외부 서비스가 변경되는 경우 본 개인정보처리방침이 변경될 수 있습니다. 변경된 내용과 시행일은 이 페이지를 통해 공개합니다.

10. 문의

개인정보처리방침 또는 앱에 관한 문의는 Google Play 스토어의 환율계산기 앱 페이지에 표시된 개발자 연락처를 이용해 주세요.
